# 🌼 12-Недельный Планер • 84 Дня Роста (Mobile Web App)

Красивое, быстрое и автономное мобильное веб-приложение для планирования 12-недельного года по методике Брайана Морана, оформленное в тёплом ботаническом стиле с ромашковым трекером привычек.

---

## 🌟 Возможности приложения

1. **☀️ Обзор (Dashboard):**
   - 12 капсул недель в верхней ленте спринта с быстрым переходом.
   - Счётчик дней (`33 из 84 дней`, `51 день осталось`).
   - Трекер темпа выполнения (`84%`) и серия продуктивных дней (`14 🔥`).
   - **Ромашковый трекер 84 дней:** каждый выполненный день расцветает золотистой ромашкой 🌼.
   - Интерактивный график динамики по всем 12 неделям с отметкой лучшей недели.

2. **🎯 5 SMART-Целей:**
   - До 5 ключевых целей спринта.
   - **Рамочки для фото:** возможность прикрепить вдохновляющее фото к каждой цели прямо с камеры или галереи телефона (с автоматическим сжатием для экономии памяти).
   - Метрики: Старт &rarr; Сейчас &rarr; Цель с автоматическим расчётом дельты (`-3.5 кг`, `+170 тыс. ₽`).
   - Шкала выполнения цели в процентах.
   - Список ключевых регулярных действий/привычек под каждую цель.
   - Таблица 12-недельных замеров (`Н1..Н12`).

3. **📝 Сегодня (Баланс времени и Задачи):**
   - Точный расчёт тайм-бюджета по ТЗ: свободные минуты (120м), буфер резерва (30%), режим «Лёгкий» = **40 минут** чистого лимита.
   - Визуальный балансир времени: показывает запланированные минуты, остаток и предупреждает о перегрузе.
   - Список задач с таймингом (`20 мин`), привязкой к целям и анимацией выполнения.
   - Эффект салюта (конфетти) при закрытии задач и тактильный отклик на смартфоне.
   - Дневная заметка и благодарность.

4. **📅 Неделя и 3-этапная рефлексия:**
   - Вертикальный обзор 7 дней недели с балансом времени.
   - Рейтинг недели золотыми звёздами (1–5 ⭐).
   - 🌿 **Что сработало?** (Победы и эффективные приёмы).
   - 🪵 **Что не сработало?** (Что сбило фокус и как исправить).
   - 💡 **Инсайты и выводы.**
   - 🎯 **Главный фокус следующей недели.**

5. **⚡ Mental Upgrade:**
   - 🔮 **Шаг 1:** Видение на 3–5 лет.
   - ❤️ **Шаг 2:** Эмоциональное «Зачем».
   - 🚫 **Шаг 3:** Великий отказ (интерактивный список того, от чего отказываетесь на 12 недель, с возможностью добавлять свои пункты).
   - ⚖️ **Шаг 4:** Цена и жертвы (готовность к усилиям).

6. **⚙️ Настройки и полная изоляция данных:**
   - **Zero-Backend:** Никаких серверов, Firebase и паролей. Данные хранятся в `LocalStorage` вашего смартфона.
   - **Изоляция:** Когда вы делитесь ссылкой с другом, у него открывается его собственный, изолированный планер — ваши данные никогда не пересекутся.
   - 📥 **Экспорт в JSON:** скачивание резервной копии в один клик.
   - 📤 **Импорт из JSON:** восстановление всех данных на новом телефоне.
   - ✨ **Сбросить к демо-данным:** вернуть образцовое наполнение из блокнота.
   - 🧹 **Очистить всё:** сделать планер чистым с нуля.

## 🚀 Как опубликовать на GitHub Pages (2 простых шага)

Ваша будущая ссылка:  
👉 **`https://louiseelgin525-design.github.io/12week-planner/`**

### Способ 1: Через сайт GitHub (без командной строки)
1. Зайдите на [github.com/new](https://github.com/new) и создайте публичный репозиторий с именем **`12week-planner`**.
2. Нажмите **«uploading an existing file»** (загрузить файлы).
3. Перетащите в окно браузера файлы из этой папки:
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
4. Нажмите зелёную кнопку **«Commit changes»**.
5. Перейдите в **Settings** (Настройки репозитория) &rarr; слева вкладка **Pages**:
   - В разделе *Branch* выберите **main** (или master) и папку **/ (root)**.
   - Нажмите **Save**.
6. Через 1 минуту ваше приложение откроется по ссылке:  
   `https://louiseelgin525-design.github.io/12week-planner/`

---

### Способ 2: Через Git в терминале (в 1 команду)
В этой папке выполните:
```bash
git init
git add .
git commit -m "Release 12-week planner"
git branch -M main
git remote add origin https://github.com/louiseelgin525-design/12week-planner.git
git push -u origin main
```
После этого включите GitHub Pages в настройках репозитория.

## 📱 Как запускать на телефоне как приложение
1. Откройте ссылку в Safari (iOS) или Chrome (Android).
2. Нажмите меню «Поделиться» или три точки &rarr; **«На экран Домой»** (Add to Home screen).
3. Приложение появится в виде удобной иконки на рабочем столе и будет открываться на полный экран без лишних рамок браузера!
